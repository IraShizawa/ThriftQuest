# SavingsRPGCore

欲しいものを「ボス」に見立てて、衝動買いを思いとどまった瞬間を、別の目標に近づく一手に変えるiPhoneアプリです。

たとえば、3万円のスニーカーを登録すると、最大HPは30,000。買い物を我慢して浮いた1,000円をスニーカーに振り分けると、貯金額は1,000円増え、残りHPは1,000減ります。「いくら貯めたか」と「あといくら必要か」を同時に確認できます。

## 主な機能

- **ボス登録**：欲しいものの名前と価格を入力し、価格をボスの最大HPに設定します。
- **攻略資金の記録**：バイトなどで稼いだ金額と、買い物を我慢して浮いた金額を記録します。
- **分配と攻撃**：攻略資金をどのボスにいくら使うか、自分で決めます。たとえば6,000円を、スニーカーに3,000円、ライブに2,000円、ゲームに1,000円と分配できます。
- **進捗と履歴**：攻撃後の貯金額と残りHPを確認し、過去の攻撃を振り返れます。
- **共有から下書き保存**：SafariやECアプリの共有メニューから商品情報を受け取り、入力した金額と一緒に下書きへ保存します。共有される情報は共有元によって異なります。
- **AIによるボス生成**：OpenAIの画像編集APIを使い、商品写真をもとに、その商品の形や色を残したオリジナルのボスイラストを生成します。

## ボスができるまで

1. 商品画像を選び、「ボスを生成」を押します。
2. 生成されたイラストを確認します。別のデザインを試したいときは「もう一度生成」、気に入ったら「このボスにする」を選びます。
3. ボス名と商品の価格を入力して登録します。

## 画面の流れ

- ボスを確認する：ホーム → ボス詳細 → 貯金額・残りHP・攻撃履歴
- 攻撃する：攻略資金を追加 → ボスごとに分配 → 攻撃結果
- 商品を共有する：商品の共有メニュー → 下書き保存 → 本体アプリで確認

## 使用技術

- Swift / SwiftUI：iPhoneアプリの画面と操作
- GameStore：ボス、攻略資金の分配、攻撃結果の状態管理
- UserDefaults：ゲームデータの端末内保存
- Share Extension：他のアプリからの商品情報の受け取り
- OpenAI API：商品画像をもとにしたボスイラストの生成
